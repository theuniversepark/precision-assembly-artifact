# 정밀조립 Zone · 2026 구축 구성

공개 웹: https://theuniversepark.github.io/precision-assembly-artifact/

3개 공정 구역, 견적 46품목과 공급사 개념형상의 대응을 검토합니다.
전체 배치 회전·확대, 품목 선택·강조, 분리 이미지, 형상 표현 범위를 제공합니다.
장비 구성 기준은 유일로보틱스 2026-10-14 견적 v3.0입니다.
공개본에는 견적 금액과 원문 행을 포함하지 않습니다.

이 모델은 개념 배치이며 실제 건물 실측 배치, 제조사 상세 CAD 또는 안전 검증 결과가 아닙니다.
웹용 모델은 표시용 색상·품목 연결 정보를 가진 개념형상을 경량화한 것입니다.
Three.js 0.180.0은 vendor/LICENSE의 MIT 라이선스로 사용합니다.
